# Pixelit

# A Pixel Drawer Application

### Overview

Pixelit is an interactive platform for creating, sharing, and animating pixel art. It fosters a collaborative environment where users can showcase their creativity and connect with others in the community.

### Key Features

- **User Profiles**: Create a profile with a custom bio and profile picture.
- **Art Creation and Animation**: Design pixel art and animate it frame-by-frame.
- **Community Interactions**: Like, comment, and bookmark favorite projects.
- **Collaboration**: Invite other users to collaborate on projects with different permission levels.
- **Download and Export Options**: Download projects with customizable settings.
- **Version Control**: Maintain version history to manage project changes effectively.

### Future Plans

- **Premium Features**: Implement licensing, high-quality downloads, and exclusive tools to support a Pro version.
